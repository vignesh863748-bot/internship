Observations

  • Div elements are block-level elements.
  • Each div starts on a new line and takes up the full available width.
  • Span elements are inline elements.
  • Span elements stay on the same line unless there is no space available.
  • Divs are commonly used for page layout and sectioning content.
  • Spans are commonly used for styling small portions of text within a line.
